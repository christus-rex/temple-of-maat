# Temple v5.5.1 — Stability & Observability Checkpoint

**Build:** `2026-08-19-v5.5.1-stability-observability`

v5.5.1 is the stabilization checkpoint for the Living Archive line. It does not replace the v5.5 archive model; it hardens how the live Temple is verified, observed, and rolled back.

## Changelog

- Added connector-visible classic commit status contexts for repository CI and deployed live-smoke verification.
- Added exact-SHA GitHub Pages verification with stale-run protection so superseded workflow runs cannot overwrite current health state.
- Replaced the fragile dependency-heavy deployed browser bootstrap with a focused Playwright Chromium path.
- Added `scripts/smoke-live-pages-v5.5.1.mjs` to verify release identity, mobile containment, Living Codex dock behavior, Seven Fires filters, mobile 16px controls, service-worker registration, Poems and Living Archive overlay stacking, same-origin network health, console errors, and screenshot evidence on phone and desktop widths.
- Expanded the machine-readable `temple-status/temple-health.json` schema with connector and live-smoke aliases plus last-successful validation timestamps.
- Added `/health/`, a unified public Temple Health dashboard for release identity, connector CI, Pages, live smoke, PWA cache revision, and cross-component commit consistency.
- Linked the in-Temple release diagnostics panel directly to Temple Health.

## Release gate

A release is green only when connector CI, GitHub Pages, and deployed live-smoke verification all report success for the same commit.

## Rollback checkpoint

The stable rollback ref for this release is the `release/v5.5.1` branch, created from the final green v5.5.1 commit after all release gates pass.

The prior stable rollback line remains available through the existing release documentation and rollback policy.
